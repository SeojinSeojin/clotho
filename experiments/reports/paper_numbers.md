## 6. Leakage

Original protocol (code reading; `reports/log_parsing_leakage_original.md`, upstream commit e8aed3d):

**Answer: yes.** Each input has one generation run (10 samples, T=0.8). It writes one JSON file, and that file supplies both the label (fraction of the 10 samples that pass) and every post-generation metric. LOHSvar's output hidden states are recorded during that same run. Tok-Prob and Tok-Ent use sample 0, which is also one of the 10 samples behind the label. Sem-Ent and LOHSvar use all 10.

Measured effect in our setting (script `log_parsing_phase3_final.py report`; leaky = label and scores share all 10 samples; `net` subtracts the shift of methods that cannot see the generations):

`net` = diff minus the mean diff of the methods that never see the generations (pre-generation and lookup: +0.024 @100, +0.021 @200). Those methods move only because the leakage-free label is noisier (5 samples, >= 3 of 5) and has a different pass rate, so `net` is the part of the change attributable to leakage.
